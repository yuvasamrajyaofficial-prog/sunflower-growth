# 🌻 Sunflower Clinic | AI SEO & Growth Engine
### Live Portfolio & Strategic Growth Proof-of-Concept for CEO Koby Conrad

A multi-page/tabbed React web application engineered to demonstrate an end-to-end patient growth system for [Sunflower Clinic](https://sunflowerclinic.com). Bridges Sunflower Sober’s **51.1K organic social community** (`@sunflowersober` 20.1K IG + 31K FB) into high-intent clinical intake, while capturing #1 Generative Engine Optimization (GEO) citations across ChatGPT Search, Perplexity AI, and Google Gemini.

---

## 🚀 Tech Stack

- **Framework:** React 19 + Vite 8 (Ultra-fast build & HMR)
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion (Page transitions, accordion reveals, hover elevations)
- **Icons:** Lucide React & Custom Brand Vectors
- **Schema:** Schema.org `MedicalWebPage`, `Physician`, `MedicalCondition`, and `FAQPage` JSON-LD
